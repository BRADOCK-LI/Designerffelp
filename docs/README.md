# Site Felpdesigner

Portfólio estático da Felpdesigner.

## Estrutura
- index.html
- styles.css
- script.js

## Links
Edite o arquivo `script.js` e troque os valores de:
- instagram
- behance
- whatsapp

## GitHub Pages
O workflow em `.github/workflows/deploy-pages.yml` está preparado para publicar a pasta `docs` automaticamente.

No GitHub, faça apenas uma vez:
**Settings > Pages > Build and deployment > Source > GitHub Actions**

Depois disso, cada atualização na branch `main` publica o site automaticamente.
